# JR Refrigerações

Projeto acadêmico da UNINASSAU para a disciplina de Maturidade em Desenvolvimento de Software. A aplicação apresenta os serviços de refrigeração do técnico Júnior em Recife/PE, com galeria, estimativa de deslocamento e formulário público de orçamento.

## Executar

```bash
cd jr_refrigerações
npm install
npm run dev
```

O Vite exibirá no terminal o endereço local da aplicação.

## Projeto

O código-fonte e a documentação completa da Aula 1 estão na pasta [`jr_refrigerações`](jr_refrigera%C3%A7%C3%B5es/README.md). Os dados ainda são demonstrativos e não há integração com backend ou autenticação.
